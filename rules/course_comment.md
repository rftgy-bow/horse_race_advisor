# 新潟競馬場、京都競馬場
- 先行有利、差し不利
- 直線が平坦で、下り坂から繋がっているため

# 東京競馬場、中京競馬場、阪神競馬場、中山競馬場
- 先行不利、差し有利
- 直線に長い/傾斜が急な坂があるため、逃げ馬は特にバテがち
- ただし稍重より重い芝は逃げ有利

# 福島競馬場
- 細かい高低差が激しく、スタミナが2割増で必要
- 開幕前半は内先行有利、後半は外差し有利

# 小倉競馬場
- 芝1200mは最初から最後まで下りのため逃げ有利
- 1800m以上は中・長距離レベルのスタミナ必要
