# 予想の振り返りから得たルール

## 1. 馬場は「表示」ではなく「当日の時計とラップ」で判定する
- 同条件（同距離・同コース）の当日レースの勝ち時計・上がり・ラップを必ず確認する。
- 「重」表示でも時計が速い（良に近い勝ち時計、上がり33〜34秒台が出る）場合は、実質的に良〜稍重の馬場として扱う。
  - その場合、重巧者血統（ゴールドシップ、オルフェーヴル、ハービンジャー等）の加点は外し、上がり性能と能力を優先する。
  - 「小柄な馬は重で不利」「雨の日に不調な騎手」といった道悪前提の減点も適用しない。
- 事例（2026/11/15 京都・重表示）
  - 7R 芝1600外 1:34.4、11R 芝2200外 2:14.7（勝ち馬上がり33.3）、12R 芝1800外 1:47.5。
  - 重巧者として評価したコガネノソラ13着、チェルヴィニア14着、チェルノボーグ16着。428kgのマトラコーニッシュが3着。

## 2. 能力指数は重賞での時計と上がりで差をつける
- 能力は横並びにせず、重賞・オープンでの走破時計と上がりで幅を大きく取る（例：GI級10点、リステッド級6点）。
- 斤量・距離変更・休み明けなどの不安要素による減点は、能力差の範囲内に留める（制約2の徹底）。
- 事例（2026/11/15）
  - 東京11R オーロC：富士S（GII）3着1:32.4のエコロアルバを「57kg・初1400m」で期待値を下げたが、最後方から上がり32.6で勝利。
  - 京都11R エリザベス女王杯：距離不安を抱えたカムニャック（GIで0.2差）が2着。

## 3. 長期休み明けの軸候補は馬体重発表後に確定する
- 休み明け（目安：12週以上）の馬を軸・上位評価にする場合は、馬体重発表（発走約1時間前）を確認してから最終判断する。
- 大幅増（+10kg以上）で、かつ成長分と説明できる材料がない場合は評価を下げる。
- 事例：ジュウリョクピエロ（24週ぶり、+16kg）が2番人気で11着。

## 4. 買い目は軸1頭に依存させない
- 3連複の全点が同じ1頭を含む構成は避ける。
- 複勝率上位5頭は、ワイドBOXまたは軸2頭流しで組み、どの1頭が飛んでも残る形にする。
- 軽視する人気馬は少額で残す（この形で京都11Rの3連複7-15-16＝5,710円を拾えた）。
- 事例：京都12Rは全3連複に⑤を入れて全滅。上位5頭内の⑯-⑭（ワイド1,000円）が1・2着だった。

## 5. 騎手の条件別の減点は、馬場の実態がその条件のときだけ使う
- 「雨・重×」などの条件別評価は、実際に時計のかかる馬場のときのみ適用する。
- 時計の出る馬場ではトップ騎手の腕を優先する。
- 事例（2026/11/15）
  - 京都11Rは武豊・川田が1-2着、京都12RはC.デムーロ・ルメールが1-2着。
  - ルメールには重表示を理由に減点を入れていたが、実際は時計の出る馬場だった。
